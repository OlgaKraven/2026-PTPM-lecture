# Учебные примеры

Python 3, стандартная библиотека `unittest`. Установка сторонних пакетов не нужна.

Откройте терминал в этой папке и выполните:

```text
python -m unittest discover -v
python mutation_demo.py
```

Основной набор проверяет исправные `delivery.py`, `inventory.py`, `order.py`. Имена случаев и данные соответствуют лекциям.

`mutation_demo.py` выполняет намеренно неверный вариант доставки в памяти. Ожидаемый вывод: `WeakCheck PASS`, `StrongCheck FAIL`. Неуспех второго теста — изучаемый результат опыта. Рабочие файлы модуля не изменяются.

Ожидаемый результат нельзя вычислять самой проверяемой функцией. При самостоятельном изменении используйте копию, сначала подтвердите обнаружение дефекта, затем восстановите правильную реализацию и повторите весь набор.
