# Учебные примеры

Python 3, стандартная библиотека `unittest`. Установка сторонних пакетов не нужна.

Откройте терминал в этой папке и выполните:

```text
python -m unittest discover -v
python mutation_demo.py
```

Основной набор проверяет исправные `delivery.py`, `inventory.py`, `order.py`. Имена случаев и данные соответствуют лекциям.

`mutation_demo.py` выполняет намеренно неверный вариант доставки в памяти. Ожидаемый вывод: `WeakCheck PASS`, `StrongCheck FAIL`. Неуспех второго теста — изучаемый результат опыта. Рабочие файлы модуля не изменяются.

Для чтения четырёх исходов запустите `python report_demo.py`. Этот отдельный демонстратор намеренно выдаёт `Ran 4 tests`, `FAILED (failures=1, errors=1, skipped=1)` и код завершения 1: один случай успешен, один содержит неверное утверждение, другой выбрасывает неожиданное исключение, четвёртый пропущен. Он не входит в стандартный `discover`, потому что имя файла не соответствует `test*.py`.

Целые тестовые файлы из развёрнутых объяснений можно создать рядом с учебными модулями под указанными на слайдах именами и запустить указанной командой. Импорты, классы и действия в этих примерах приведены полностью. Отдельные методы на остальных слайдах помечены как части существующего класса.

Ожидаемый результат нельзя вычислять самой проверяемой функцией. При самостоятельном изменении используйте копию, сначала подтвердите обнаружение дефекта, затем восстановите правильную реализацию и повторите весь набор.

Справочные материалы:

- [Документация Python unittest](https://docs.python.org/3/library/unittest.html) — точное поведение утверждений и запуска.
- [ISTQB Foundation Level](https://istqb.org/certifications/certified-tester-foundation-level-ctfl-v4-0/) — понятия тестирования и техники выбора данных.
