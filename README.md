# Поддержка и тестирование программных модулей

МДК.01.02. Лекции для 4 и 5 семестров.

Учебный курс: восемь двухчасовых лекций. От ручной проверки и выбора данных — к модульным тестам, изоляции зависимостей и сопровождению исправлений.

Установка: `npm ci`. Разработка: `npm run dev`. Сборка: `npm run build`. Проверка содержания: `npm run validate`.

Исходное содержание и сценарии находятся в `authoring/`, учебные примеры на Python — в `examples/`. Сборка переносит слайды в `public/course.json`, сценарий панели — в `public/teaching/notes.json`. В `docs/` сохраняются карта программы, источники и результаты проверок.

В каталоге можно выбрать семестр и лекцию. «Режим показа» открывает отдельное окно аудитории; скрытые ответы показываются отдельной командой. Профиль преподавателя заполняется через меню «Преподавателю». Печать лекции или семестра доступна из каталога.
