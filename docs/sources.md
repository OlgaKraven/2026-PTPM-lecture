# Источники и область применения

Основой структуры является программа МДК.01.02, предоставленная пользователем 25 октября 2026 года. Официальные часы и компетенции сохранены в карте программы. Учебные правила функций и данные кейсов условные и сформулированы в самих заданиях.

Из готовых проектов использованы:

- Ермакова А. Н. «Управление ИТ-проектами. Ч. I» — библиографическая запись из ОКФКС; применяется к требованиям, контролю качества, изменениям и сопровождению. Карточка издателя просмотрена: https://www.iprbookshop.ru/books/156620/details. Полный текст не заявляется прочитанным.
- Гринченко Н. Н., Громов А. Ю., Хизриева Н. И. «Проектирование информационных систем» — библиографическая запись из ПиДИС, `app/course.ts`; применяется как дополнительная основа для проверяемых требований и границ модуля. Внешняя карточка при проверке недоступна; сведения сохранены по существующему проекту. Содержание конкретных страниц не приписывается.

Точные определения и техническое поведение сверены по первичным материалам:

- ISTQB CTFL: https://istqb.org/certifications/certified-tester-foundation-level-ctfl-v4-0/ — основы тестирования, техники выбора данных, дефекты, сопровождение.
- Python Software Foundation: https://docs.python.org/3/library/unittest.html — assertEqual, assertRaises, TestCase, subTest, фикстуры, обнаружение и запуск тестов. Примеры используют стандартную библиотеку и не требуют стороннего фреймворка.

Из старых проектов не переносились учебники по сетевой архитектуре, экономике и информационной безопасности: они не являются профильной литературой для этих лекций. Выбранные учебники широкого профиля не выдаются за специальные руководства по модульному тестированию.

Папка https://disk.yandex.ru/d/C5-55HsqSBpVCQ проверена через публичный API Яндекс Диска 25 октября 2026 года: название соответствует дисциплине, доступных файлов на момент проверки — 0. Ссылка сохранена; содержимое не выдумывается.

Оболочка: локальный пакет lecture-engine из текущего готового проекта ОКФКС и согласованный CSS оформления. Содержание ОКФКС не переносится. Новый маскот создан для проверки программных модулей по референсам навыка lecture-rhino. Логотипы и шрифты взяты из согласованного шаблона.
