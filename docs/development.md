# Разработка

Установка: `npm ci`. Разработка: `npm run dev`. Сборка: `npm run build`. Проверка содержания: `npm run validate`.

Учебные примеры: `python -m unittest discover -v` и `python mutation_demo.py` в каталоге `examples`.

Исходные темы находятся в `authoring`. Сборка формирует `public/course.json`, пакет заметок `public/teaching/notes.json`, ключи `public/assessment.json` и самостоятельные случаи `public/question-supplements.json`. Связные MD преподавателя и карта соответствия формируются локально в игнорируемом `private/teacher`; хранение преподавательских текстов — в BrainM. В публичную сборку входят только необходимые JSON.

Структура и взаимодействия сверены с `OlgaKraven/2026-OKFKS-lecture`, commit `e36d019`. Для ПТПМ сохранены три предметных вопроса в каждой лекции и часы РПД. На каждый вопрос приходятся объяснение, разобранный и изменённый случаи, типичная ошибка, вывод, самостоятельная задача и четыре вида самопроверки.

`src/infographics`, `src/lab`, `src/presentation` используют компоненты текущего ОКФКС. Данные дисциплины и четыре разветвлённые схемы ПТПМ находятся отдельно, в `authoring/diagrams.mjs` и `src/infographics/data/ptpm.json`.

Отчёты проверок и карта программы находятся в `docs`; они не показываются в учебном каталоге и на слайдах.
