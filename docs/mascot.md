# Маскот дисциплины

Сюжет: носорог в фирменной красной куртке анализирует результаты проверки модуля на мониторе и в карточке тест-кейсов. Референс персонажа и отдельный знак — из ресурсов навыка lecture-rhino. Логотип в шапке — отдельный оригинальный ресурс шаблона.

Задание изображения: сохранить серого полуреалистичного носорога с двумя рогами, красную университетскую куртку с серыми рукавами и белой угловой нашивкой, спокойное сосредоточенное выражение, красную подсветку и тёмную среду. Новое действие — анализ результатов тестирования за клавиатурой, карточка с галочками и крестиком, графические строки проверок на мониторе без случайного текста. Композиция — круглая сцена, прозрачность вне круга, без обрезанных рогов и рук, без жёлтого и водяных знаков.

Осмотрены лицо, поза, руки, характерный знак, предметный сюжет. Техническая проверка PNG: RGBA, 1254×1254; alpha четырёх углов равен 0. Исходный файл хранится как `public/brand/ptpm-rhino.png`.
